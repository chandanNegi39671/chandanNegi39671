
# 🤟 07 — SIGNSPEAK

### Real-Time Word-Level Sign Recognition

**Repository:** [SIGNSPEAK](https://github.com/chandanNegi39671/SIGNSPEAK)

SIGNSPEAK uses MediaPipe hand landmarks and an LSTM sequence model to recognize complete signs rather than isolated frames.

### Computer Vision Pipeline

```text
Camera Frame
     │
     ▼
MediaPipe
     │
     ▼
21 Hand Landmarks
     │
     ▼
x / y / z coordinates
     │
     ▼
126 Features / Frame
     │
     ▼
30-Frame Temporal Buffer
     │
     ▼
LSTM
     │
     ▼
Softmax
     │
     ▼
Word + Confidence
     │
     ▼
Live Caption
```

### Feature Representation

Each frame contains:

```text
21 landmarks × 3 coordinates
= 63 features per hand
```

With two hands:

```text
42 landmarks × 3 coordinates
= 126 features / frame
```

Temporal sequence:

```text
30 frames × 126 features
= 30 × 126 input tensor
```

### Model

```text
Input
(30, 126)
   │
   ▼
LSTM — 64 units
   │
   ▼
Dropout
   │
   ▼
LSTM — 128 units
   │
   ▼
Dropout
   │
   ▼
Dense
   │
   ▼
Softmax
```

### Interfaces

* React + Vite web application
* Flask REST backend
* desktop Tkinter application
* real-time camera processing
* transcript generation
* confidence thresholding

# 🧪 Development Philosophy

### 1. Reproducibility

Prefer:

```text
requirements.txt
.env.example
configuration modules
deterministic seeds
versioned models
```

### 2. Separation of Concerns

```text
Router
  ↓
Service
  ↓
Repository
  ↓
Database
```

rather than putting all logic inside API routes.

### 3. Model Isolation

ML models should be loadable independently from the API layer.

```text
Model
   ↓
Inference Service
   ↓
API Endpoint
```

### 4. Fail-Safe AI

When an AI dependency fails:

```text
LLM unavailable
      ↓
Deterministic fallback
      ↓
Human review / safe default
```

rather than silently returning an unsafe result.
